Usar o modelo de verdade

O OmniVoice roda no computador que serve este site — não no celular. Instale o modelo nessa máquina e reinicie o servidor: 

pip install omnivoice
OMNI_BACKEND=omnivoice ./run.sh

Na primeira execução o checkpoint é baixado do HuggingFace (alguns GB). Uma GPU NVIDIA, Apple Silicon ou Intel Arc deixa a geração bem mais rápida.

Instalar no celular

No Chrome ou Safari, abra o menu do navegador e escolha “Adicionar à tela de início”. O app passa a abrir em tela cheia, sem a barra de endereço.
