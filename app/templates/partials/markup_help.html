{# Ajuda das tags: o que é real no modelo e o que é aproximação. #}

Tags do editor

Escreva a tag antes do trecho que ela deve afetar. Uma tag de emoção vale só até a próxima tag ou pausa — não contamina o resto do capítulo.

Pausas exatas

O silêncio é inserido no áudio depois da síntese, então a duração é exata.

  • [pause] — {{ '%.1f'|format(pauses.pause) }}s (ajustável em Ajustes)
  • [pause=1.2] — exatamente 1,2 s
  • [long-pause] — {{ '%.1f'|format(pauses.long_pause) }}s (ajustável em Ajustes)

Interpretação

O OmniVoice controla o sussurro de verdade. As outras emoções não existem no modelo: o Studio as aproxima mudando ritmo e intensidade, então trate-as como experimentais e confie no ouvido.

    {% for item in catalog.style %}
  • {{ item.tag }} — {{ item.label }} {% if item.real %}real {% else %}aprox.{% endif %} {{ item.description }}
    • {% endfor %}

Uma tag desconhecida nunca é falada: o editor avisa e a ignora na geração, mas o seu texto continua intacto.
